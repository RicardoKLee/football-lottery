# 竞彩足球投注方案推荐 Skill

本 Skill 旨在指导 Agent 以**资深精算师（Actuary）**的专业角色，结合竞彩足球的实时赔率与十因子比赛预测模型，通过精算学、概率论、风险控制模型（如期望值 EV、凯利公式 Kelly Criterion）进行严谨的定量投资分析，为用户输出并保存最科学、最符合不同风险偏好（追求稳健与追求高 ROI）的投注方案。

## 准备阶段：运行预测与拉取竞彩赔率

在接收到用户的日期或特定场次请求后，必须严格执行以下双重数据准备流程，确保投注推荐**完全、严格基于 `/match-prediction` 的预测结论**：

1. **运行比赛预测**：
   对于需要分析的每一场比赛，必须**首先运行 `match-prediction` Skill** 进行十因子定量加权分析，生成完整的预测报告并保存在 `output/` 目录下（例如 `output/20260615_西班牙_vs_佛得角.md`）。

2. **拉取实时竞彩赔率**：
   运行 Python 脚本获取指定日期的竞彩比赛列表及 HAD（胜平负）、HHAD（让球胜平负）、TTG（总进球数）、HAFU（半全场）、CRS（比分）等玩法的实时赔率：
   ```bash
   python3 scripts/fetch_lottery_data.py --date "<YYYY-MM-DD>"
   ```

3. **运行投注方案生成脚本**：
   运行专门的严格投注推荐脚本，该脚本会自动扫描 `output/` 目录下的所有比赛预测报告，提取胜平负、比分和总进球数的预测结论，与实时竞彩赔率进行对比，计算期望值（EV）并生成最终的投注方案报告：
   ```bash
   python3 scripts/generate_betting_recommendation_strict.py --date "<YYYY-MM-DD>"
   ```

## 核心分析框架：提成率、归一化概率与期望值（EV）

Agent 必须执行以下完整的精算数据处理链：首先从体彩实时赔率中计算庄家抽水提成率，接着通过比例归一化还原市场隐含概率，最后利用黄金分割比例（0.618 模型 + 0.382 市场）混合出最终决策概率，以此进行期望值（EV）定量计算与资金分配。

### 1. 庄家抽水提成率与返还率计算
对于某玩法下所有互斥的投注选项，其赔率分别为 $O_1, O_2, \dots, O_n$。
- **原始隐含概率**：$IP_i = \frac{1}{O_i}$
- **超额赔率总和（Overround）**：$S = \sum_{i=1}^n \frac{1}{O_i}$
- **庄家抽水提成率（Margin / Vig）**：$M = S - 1$
- **官方理论返还率（Payout Ratio）**：$R = \frac{1}{S}$

### 2. 归一化市场隐含中奖概率（去抽水概率）
利用比例分配法（Proportional Method）消除庄家抽水的影响，还原市场的无偏见共识概率：
$$P_{implied}(i) = \frac{IP_i}{S} = \frac{\frac{1}{O_i}}{\sum_{j=1}^n \frac{1}{O_j}}$$

### 3. 双源黄金比例概率融合
为了将模型的深度预测优势（Alpha）与市场的资本流共识（Beta）有机结合，最终决策概率 $P_{final}$ 必须采用**黄金分割加权比例（0.618 : 0.382）**进行线性混合：
$$P_{final}(i) = 0.618 \times P_{predicted}(i) + 0.382 \times P_{implied}(i)$$
- $P_{predicted}$：由十因子预测模型推导出的该选项发生概率（来自 `match-prediction`）。
- $P_{implied}$：通过实时赔率计算并去抽水后的归一化中奖概率。

### 4. 期望值（EV）计算公式
对于任意投注选项，其最终决策期望值计算公式为：
$$EV = P_{final} \times O - 1$$
- **判定标准**：
  - **$EV > 0$**：代表该投注具有**正期望值（性价比高）**，属于长期投资有利可图的“价值投注”（Value Bet）。
  - **$EV \le 0$**：代表该投注性价比低，不建议作为首选。

### 5. 凯利公式仓位控制（Kelly Criterion）
对于 $EV > 0$ 的价值投注，使用凯利公式计算推荐的投注资金比例（仓位 $f^*$）：
$$f^* = \frac{EV}{O - 1}$$
为了控制风险，实际推荐时采用**半凯利（Fractional Kelly, 比例为 50%）**进行风险稀释：
$$\text{推荐仓位} = 0.5 \times f^*$$

### 3. 固定本金（200元）分配与最低投注限制
- **固定本金**：为了提供最符合大众日常娱乐的实操账单，每次计算和输出黄金投注方案时，必须**统一按照 200 元（RMB）的固定本金**进行各档位资金的精密拆分。
- **最低投注约束**：根据中国体育彩票的相关规定，**单次最低投注金额必须为 2 元**（即 1 注票价，且必须为 2 元的整数倍，如 2, 4, 6, 8, ... 元）。
  - 在计算分配资金时，如果某高风险/极轻仓选项根据比例得出的计算金额小于 2 元（或非整数），必须**强制向上取整或向下调整为 2 元**。
  - 所有分配金额必须是 **2 元的整数倍**，最终各选项分配金额之和必须**刚好等于 200 元**（若因四舍五入无法对齐，可通过微调高概率胆码的资金来补齐）。

## 投注方案组合策略

作为一名专业的精算师，Agent 必须根据不同的风险偏好与投资目标，对计算出的正 EV 选项进行精算分级和组合，设计以下两类核心推荐方案：

### 1. 追求稳健策略（Low Risk, Stable Growth）
该策略旨在最大化胜率，严格控制回撤，适合追求稳健、规避高风险的投资者。
- **稳健单场推荐（胜平负/让球胜平负单场）**：
  - 筛选出 $EV > 0$ 且预测概率 $P \ge 55\%$ 的选项。优先选择主不败或客不败等高胜率受让盘口。
  - 推荐仓位控制在 3% - 5% 之间。
- **稳健 2串1 组合**：
  - 选择 2 场预测概率极高（$P \ge 60\%$）且 $EV > 0$ 的稳胆选项进行串关。
  - 组合总胜率控制在 $35\%$ 以上，总赔率介于 $2.0 \sim 3.5$ 之间，确保中奖确定性。

### 2. 追求投资回报率策略（High ROI, Capital Appreciation）
该策略旨在正 EV 的前提下最大化长期资金增长率，博取超额收益，适合追求高投资回报率、有一定风险承受能力的投资者。
- **高 ROI 性价比串关（2串1 / 3串1）**：
  - 选择 2-3 场 $EV \ge 5\%$ 且彼此独立的比赛，将高性价比的选项组合成混合过关。
  - 组合总赔率介于 $3.5 \sim 8.0$ 之间，利用期望值乘数效应实现资金的快速增值。
- **高回报特色玩法博冷（比分/半全场/总进球数）**：
  - 结合预测的精确比分和总进球数，在比分（CRS）或半全场（HAFU）中寻找赔率极高（$O \ge 8.0$）且 $EV > 0$ 的冷门高价值选项。
  - 推荐仓位控制在 1% - 2% 之间（娱乐轻仓），以极小的风险博取极高的回报。

## 输出与文件保存规范

### 1. 文件保存与命名规范
- **保存路径**：本项目根目录下的 `output/` 文件夹（若不存在则自动创建）。
- **文件名规则**：`日期（年月日）_投注方案.md`。
  - **日期格式**：采用 `YYYYMMDD` 八位数字格式。日期以比赛实际进行的北京时间/竞彩开售日期为准（例如：`20260620_投注方案.md`）。
- **保存内容**：必须包含完整的投注方案报告，包含概述表格、EV定量分析表、推荐组合及投资建议。
