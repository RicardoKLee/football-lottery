# 足球比赛结果加权预测 Skill

本 Skill 旨在指导 Agent 针对 2026 年美加墨世界杯小组赛的特定场次，执行系统性的专业数据检索与十因子定量加权分析，以输出高精准度的比赛预测（包含胜平负、比分与总进球数），并呈现为结构化表格。

## 准备阶段：执行 Python 数据抓取

在开始对具体比赛进行预测前，必须**首先运行项目自带的 Python 脚本**以获取最新的 ELO 积分及两队历史胜平负基准数据。
运行命令：
```bash
python3 scripts/fetch_match_data.py "<主队名称>" "<客队名称>"
```
读取脚本返回的 JSON 数据，提取以下关键信息：
- 两队的实时 ELO 积分及世界排名
- ELO 理论胜、平、负概率
- 历史总战绩数据

## 检索阶段：补充实时多维度数据

对于脚本无法自动获取的临场及环境动态信息，必须使用 `WebSearch` 工具检索专业网站（如 **FIFA官网**, **Transfermarkt**, **WhoScored**, **WorldReferee** 以及各国家队/战队官网）获取以下事实。检索必须确保时效性（设定时间为 2026 届美加墨世界杯）。

1. **人员伤病停赛与门将高阶状态**：核心球员伤停、身价和战术地位。**必须特别注意，伤病情况必须以国际足联（FIFA）官方公布的最新的实时大名单和临场伤病报告为准，严禁简单使用俱乐部赛季末的历史伤病数据**。例如，拉米内·亚马尔虽在巴塞罗那俱乐部赛季末期因伤缺席，但在世界杯首轮对阵佛得角中已替补出战15分钟。对于此类情况应充分鉴别，按照“有伤病隐患、出战成疑但有出场可能、预计限制出场时间”进行分析。**同时必须检索主力门将的高阶扑救净胜效能（PSxG - Post-Shot Expected Goals +/-），分析首发门将的即时状态，神勇门将是弱队抵御强攻、形成爆冷平局的决定性防线。**（来源：FIFA官网、Transfermarkt、FBref / Sofascore）。
2. **打法风格与首发名单**：两队的阵型与打法风格。**必须结合两队历史场均与本届首轮高阶数据（控球率、场均/首轮进攻与危险进攻、角球数，以及两队身高超过 185cm 的球员人数差、定位球防守与进球比率）进行定量战术克制与定位球高空压制分析。**（来源：WhoScored / SofaScore）。
3. **出战人员市场总身价**：两队参赛大名单或预计首发球员的市场总估值（来源：Transfermarkt）。
4. **天气与地理环境**：比赛球场的城市、海拔高度（如墨西哥城阿兹特克球场 2200 米海拔）、湿度和开球时间的天气预报。
5. **主裁判执法尺度与本届纪律**：主裁判的历史场均红黄牌数、两队在本届比赛中已拿到的红黄牌数据、点球数以及停赛风险（来源：FIFA官网、WorldReferee）。
6. **战意与本届表现**：小组积分榜形势、净胜球需求、是否已提前出线或淘汰。**必须结合两队首轮高阶进攻效能数据（射门数、射正次数、射偏次数、半场领先/落后情况）进行分析。**（来源：FIFA官网）。

## 核心分析框架：十因子定量加权系统

Agent 必须针对以下十个预测因子对主队（Team 1）相对于客队（Team 2）的优势进行评分。
**评分标准**：每个因子的优势分（Advantage Score, 记为 $A_i$）范围为 **-10 到 +10**：
- **正分（+1 到 +10）**：表示主队（T1）在该维度占优，分值越大优势越明显。
- **负分（-1 到 -10）**：表示客队（T2）在该维度占优，绝对值越大优势越明显。
- **零分（0）**：表示两队在该维度完全均势。

每个因子乘以其固定的权重比重（$W_i$），累加得到**总加权优势分**（$S = \sum A_i \times W_i$），范围为 **-10.0 到 +10.0**。

### 十大预测因子权重及评分指南

| 因子序号 | 预测因子 | 权重 ($W_i$) | 评分指南与数学模型 |
| :--- | :--- | :--- | :--- |
| 1 | **ELO积分与走势** | **22%** | 基准分 = (主队ELO - 客队ELO) / 50，上限为 $\pm 8.0$。结合近期ELO上升或下降趋势调整 $\pm 2.0$ 分。 |
| 2 | **打法风格与定位球攻防** | **17%** | 评估战术克制与定位球高空压制。如高效防反型面对重控球但退防慢的球队，防反方得 +4 到 +6 分；高空及定位球优势显著（身高 >185cm 球员人数占优且定位球进球率高）可得 +2 到 +4 分。 |
| 3 | **人员伤病与门将状态** | **15%** | 评估伤停对战斗力的损害与主力门将即时状态。根据伤停球员身价占比与战术替代性定量。同时结合主力门将的扑救净胜效能（PSxG +/-），神勇门将可为主队增加 +1 到 +3 分的平局/防守保障。 |

| 6 | **最新表现与战意** | **10%** | 小组赛形势分析。如主队必须获胜才能出线，而客队已提前出线且预计将轮换主力，主队战意极强，得 +6 到 +10 分。 |

| 8 | **近期20场胜平负** | **5%** | 对近 20 场比赛进行分类加权，正式比赛权重为 1.0，非正式比赛（如友谊赛、训练赛等）权重降至 0.4。根据加权胜率和加权不败率差值进行评分。评分差每 10% 对应 $\pm 1.5$ 分，上限 $\pm 5.0$ 分。 |

### 胜平负方向预测标准
根据最终计算出的**总加权优势分 $S$** 划定比赛的基本走向：
- **$S > +2.5$**：预测**主队独赢 (T1 Win)**。若 $S > +5.0$，则为深盘稳赢。
- **$-1.5 \le S \le +1.5$**：预测**双方战平 (Draw)**。双方实力极度胶着，战术或伤病相互制约。
- **$S < -2.5$**：预测**客队独赢 (T2 Win)**。若 $S < -5.0$，客队稳赢。
- **$+1.5 < S \le +2.5$** 或 **$-2.5 \le S < -1.5$**：属于模糊过渡带，须倾向于优势方**不败双平**（胜/平 或 负/平），结合进球数进行安全预测。

## 比分与总进球数预测逻辑：数学模型构建与泊松分布计算

为了避免主观凭空猜测比分，本系统采用**双泊松分布（Double Poisson Distribution）数学模型**，结合**十因子总加权优势分 $S$** 与两队的**ELO进攻/防守参数**，对精确比分概率进行连续计算。

### 1. 核心数学模型：双泊松分布公式
设主队（Team 1）的期望进球率为 $\lambda$，客队（Team 2）的期望进球率为 $\mu$。由于在 2026 美加墨世界杯赛前可以通过高阶攻防穿透确定期望总进球数 $txG_{proj}$，我们通过总加权优势分 $S$ 直接推导两队的期望进球率：
$$\lambda = \max\left(0.1, \frac{txG_{proj} + k \cdot S}{2}\right)$$
$$\mu = \max\left(0.1, \frac{txG_{proj} - k \cdot S}{2}\right)$$

*其中*：
- $txG_{proj}$：两队攻防风格基准下的总期望进球数（由打法风格、门将 PSxG、高海拔及历史大球战意综合评定，默认为 2.4 球）。
- $S$：十因子总加权优势分（范围 $-10.0$ 至 $+10.0$）。
- $k$：优势分-进球转换率系数（设为 $k = 0.30$。例如 $S = +5.0$，对应进球期望差值达 $1.5$ 球）。
- 约束条件：期望进球率下限设为 $0.1$ 以免计算失真。

根据泊松概率质量函数，任意精确比分 $X$ - $Y$ 的发生概率 $P(X, Y)$ 计算公式为：
$$P(X, Y) = \frac{e^{-\lambda} \lambda^X}{X!} \times \frac{e^{-\mu} \mu^Y}{Y!}$$

### 2. 引入 ELO 进攻与防守参数修正
本系统引入 **ELO 进攻评级（$Elo_{att}$）**与 **ELO 防守评级（$Elo_{def}$）**，对基础期望进球率进行高阶战术修正。
- **ELO 进攻评级（$Elo_{att}$）**：在基础 ELO 积分上，结合两队首轮及近期各项赛事的前场创造力、非点球预期进球（np-xG）、射正率（Shots on Target %）进行加减修正。
- **ELO 防守评级（$Elo_{def}$）**：在基础 ELO 积分上，结合两队防守落位深度、防空争顶成功率以及主力门将的高阶扑救净胜效能（PSxG +/-）进行加减修正。

在评估**“因子 2（打法风格与定位球攻防）”**和**“因子 3（人员伤病与门将状态）”**时，两队最新的 ELO 攻防参数差异直接决定其进球期望修正：
- 主队期望修正：$\lambda' = \lambda \times 10^{\frac{Elo_{att, 1} - Elo_{def, 2}}{800}}$
- 客队期望修正：$\mu' = \mu \times 10^{\frac{Elo_{att, 2} - Elo_{def, 1}}{800}}$

### 3. 基于随机噪声与临场纪律扰动的蒙特卡洛（Monte Carlo）采样修正
由于足球比赛具有极强的偶然性（物理运气底噪、主裁判红黄牌惩罚造成的减员、禁区内偶发点球判罚），本系统在泊松期望之上，进一步引入**基于临场事件的随机扰动蒙特卡洛采样模型**，进行 10,000 次模拟采样以修正比分推荐：

#### 3.1 物理运气白噪声（White Noise）
物理运气（如门柱、折射、天气风速阻力）对两队的临场期望进球率（$\lambda'$ 与 $\mu'$）产生 log-normal 分布的白噪声扰动（标准差设为 $\sigma = 15.0\%$）：
$$\lambda_j = \lambda' \cdot e^{\epsilon_{h, j}}, \quad \mu_j = \mu' \cdot e^{\epsilon_{a, j}}, \quad \epsilon \sim N(0, \sigma^2)$$

#### 3.2 主裁判红黄牌惩罚（Red Cards）扰动
主裁判的执法严厉程度（场均黄牌数 $Y_{ref}$）与两队的场均犯规数 $F$ 共同决定了红牌减员概率。世界杯单场基准红牌率设为 $6.0\%$：
$$P_{red, h} = \min\left(0.15, \frac{Y_{ref}}{4.5} \times \frac{F_{home}}{12.0} \times 0.06\right), \quad P_{red, a} = \min\left(0.15, \frac{Y_{ref}}{4.5} \times \frac{F_{away}}{12.0} \times 0.06\right)$$
在每次采样中，进行伯努利试验（Bernoulli Trial）。若某队（如主队）触发红牌，其面临非战斗减员，将导致客队期望进球率 $\mu_j$ 飙升 $30\%$（防线出现破绽），而主队进攻期望 $\lambda_j$ 萎缩 $10\%$。

#### 3.3 点球判罚（Penalties）扰动
主裁判点球判罚率 $P_{pen, ref}$（场均点球数）与两队的场均危险进攻（Dangerous Attacks, 记为 $DA$）正相关。单场判罚至少一个点球的联合概率为：
$$P_{penalty} = \min\left(0.40, P_{pen, ref} \times \frac{DA_{home} + DA_{away}}{75.0} \times 0.8\right)$$
点球在两队间的分配概率基于其在对方禁区内的统治力（$\frac{DA_{home}}{DA_{home} + DA_{away}}$）。点球的罚入概率（Bernoulli Trial）根据国际 A 级赛历史均值设为 $76\%$。

#### 3.4 三手比分梯级推荐决策规则
通过 10,000 次蒙特卡洛模拟，对所有事件组合产生的精确比分进行频数统计，并按最终模拟概率 $P_{sim}(X, Y)$ 自动输出以下三个梯度推荐：
1. **首选（第一手推荐）**：取模拟发生概率绝对值最高的比分，即 $\arg\max_{(X,Y)} P_{sim}(X, Y)$（通常最契合胜平负基准走向）。
2. **次选（第二手推荐）**：模拟发生概率排名第二的变轨比分。
3. **第三手推荐（防冷/高收益投注）**：模拟概率中具有对冲性质的高频比分（如在过渡带时强制推荐平局比分进行极限防守）。
