# Consensus Metrics and Decision Guidelines (共识指标与判定标准指南)

本文件作为 `match-prediction` Skill 的扩充参考指南，用于记录足球比赛预测精算模型中的通用共识指标、数学定义及判定区间标准。

---

## 一、 核心共识指标定义与判定区间

### 1. 期望进球数 (Expected Goals, xG)
- **定义**：根据射门位置、射门方式、传球质量、防守压力等高阶数据，评估单场比赛中一支球队理论上应取得的平均进球数。
- **基准期望推导**：
  在精算模型中，结合两队的加权总优势分 $S \in [-10, +10]$ 和基准项目总进球期望 $txG_{proj}$（默认 2.40 球），主队基础期望进球数 $\lambda_{base}$ 与客队基础期望进球数 $\mu_{base}$ 推导公式为：
  $$\lambda_{base} = \max\left(0.1, \frac{txG_{proj} + k \cdot S}{2}\right)$$
  $$\mu_{base} = \max\left(0.1, \frac{txG_{proj} - k \cdot S}{2}\right)$$
  *(其中转换系数 $k = 0.30$)*

---

### 2. 净期望进球差 / 净胜球 (Goal Difference / Expected Goal Difference, xGD)
- **数学定义**：双方期望进球数之差。约定以**主队为被减数（$\lambda$）**，**客队为减数（$\mu$）**作差：
  $$\text{xGD} = \lambda - \mu$$

- **判定区间与实战含义映射**：

#### (1) 当 $\text{xGD} \ge 0$ （主队期望更高或持平）
| 净胜球差区间 ($\text{xGD}$) | 战力对抗判定 | 预测指导意义 |
| :--- | :--- | :--- |
| **$0 \le \text{xGD} < 0.3$** | **双方实力在伯仲之间** | 比赛势均力防，胜负难料。首选平局或双选对冲，比分集中在 1-1 / 0-0 / 1-0。 |
| **$0.3 \le \text{xGD} \le 0.6$** | **主队略占优势** | 主队小幅占优但防爆冷。首选主胜（1-0 / 2-1），防平局（1-1）。 |
| **$0.6 < \text{xGD} \le 1.0$** | **主队优势明显** | 主队控制比赛节奏，胜率极高。首选主胜（2-0 / 2-1 / 3-1），让球玩法倾向主胜/让平。 |
| **$\text{xGD} > 1.0$** | **主队拥有碾压优势** | 实力悬殊呈单向碾压。首选主队大胜（3-0 / 4-0 / 3-1），让球玩法建议让胜/让平。 |

#### (2) 当 $\text{xGD} < 0$ （客队期望更高，对应净胜球绝对值）
| 净胜球差区间 ($\text{xGD}$) | 绝对值区间 | 战力对抗判定 | 预测指导意义 |
| :--- | :--- | :--- | :--- |
| **$-0.3 < \text{xGD} < 0$** | **$0 < \vert\text{xGD}\vert < 0.3$** | **双方实力在伯仲之间** | 比赛势均力敌，胜负难料。首选平局或双选对冲，比分集中在 1-1 / 0-0 / 0-1。 |
| **$-0.6 \le \text{xGD} \le -0.3$** | **$0.3 \le \vert\text{xGD}\vert \le 0.6$** | **客队略占优势** | 客队小幅占优。首选客胜（0-1 / 1-2），防平局（1-1）。 |
| **$-1.0 \le \text{xGD} < -0.6$** | **$0.6 < \vert\text{xGD}\vert \le 1.0$** | **客队优势明显** | 客队掌控局势，胜率较高。首选客胜（0-2 / 1-2 / 1-3），让球玩法倾向客胜/让平。 |
| **$\text{xGD} < -1.0$** | **$\vert\text{xGD}\vert > 1.0$** | **客队拥有碾压优势** | 客队实力单向碾压。首选客队大胜（0-3 / 0-4 / 1-3），让球玩法建议让负/让平。 |

### 3. 模型胜平负概率 vs 市场胜平负预期概率

- **基本归一化要求**：
  无论是模型预测还是市场预期，胜平负三项概率（主胜 $P_h$、平局 $P_d$、客胜 $P_a$）之和必须**严格归一化等于 100%**：
  $$P_{home} + P_{draw} + P_{away} = 100\%$$

- **概率来源定义**：
  1. **模型胜平负概率 ($P_{model}$)**：
     通过参照 [`reference.md`](reference.md) 中的标准精算预测流程（包含十因子定量加权、双泊松期望进球及蒙特卡洛随机扰动模拟）推算得出的理论真实概率。
  2. **市场胜平负预期概率 ($P_{market}$)**：
     通过机构/竞彩官方实时胜平负赔率（$O_h, O_d, O_a$）扣除抽水 margin 后反推归一化的隐含概率：
     $$\text{Margin} = \frac{1}{O_h} + \frac{1}{O_d} + \frac{1}{O_a} - 1$$
     $$P_{market, h} = \frac{1 / O_h}{1 + \text{Margin}}, \quad P_{market, d} = \frac{1 / O_d}{1 + \text{Margin}}, \quad P_{market, a} = \frac{1 / O_a}{1 + \text{Margin}}$$

- **核心关键判别逻辑**：

| 现象与背离特征 | 逻辑根因与对冲分析 | 预测与投注决策指导 |
| :--- | :--- | :--- |
| **1. 模型与市场走向不一致**<br>*(例：模型看好主队 $P_{model, h} > P_{model, a}$，但市场看好客队 $P_{market, a} > P_{market, h}$)* | **模型可能存在误判或漏判**。<br>市场资金与赔率变动通常包含了最新的临场关键伤停、内部军心、战意微调或天气变故。 | 必须触发警报！复查十因子输入，**不可盲目单选**，建议首选双选对冲或放弃该场投注。 |
| **2. 模型低估主队**<br>*(例：$P_{market, h} > P_{market, m} + 5\%$，市场给出的主胜概率显著高于模型预测)* | **市场预期比模型更看好主队**。<br>机构与大资金掌握了模型未完全量化的隐藏利好（如主场魔鬼氛围、战术严重克制等）。 | **顺应市场热度与资金流，跟市场走**。倾向选择主队不败（主胜/平局）。 |
| **3. 模型高估主队**<br>*(例：$P_{model, h} > P_{market, h} + 5\%$，模型预测的主胜概率显著高于市场)* | **模型过于乐观**。<br>模型可能过度依赖历史 Elo 或过往战绩，忽视了主队体能衰竭、战意不足或市场诱导。 | **需谨慎考虑投注选择**。严禁重仓主胜，防范诱盘，重点关注让球客胜或平局防冷。 |
