# Consensus Metrics and Decision Guidelines (共识指标与判定标准指南)

本文件作为 `match-prediction` Skill 的扩充参考指南，用于记录足球比赛预测精算模型中的通用共识指标、数学定义及判定区间标准。

---

## 一、 核心共识指标定义与判定区间

### 1. 期望进球数 (Expected Goals, xG)
- **定义**：根据射门位置、射门方式、传球质量、防守压力等高阶数据，评估单场比赛中一支球队理论上应取得的平均进球数。
- **基准期望推导**：
  在精算模型中，结合两队的加权总优势分 $S \in [-10, +10]$ 和基准项目总进球期望 $txG_{proj}$（默认 2.40 球），主队基础期望进球数 $\lambda_{base}$ 与客队基础期望进球数 $\mu_{base}$ 推导公式为：
  $$\lambda_{base} = \max\left(0.1, \frac{txG_{proj} + k \cdot S}{2}\right)$$
  $$\mu_{base} = \max\left(0.1, \frac{txG_{proj} - k \cdot S}{2}\right)$$
  *(其中转换系数 $k = 0.30$)*

---

### 2. 净期望进球差 / 净胜球 (Goal Difference / Expected Goal Difference, xGD)
- **数学定义**：双方期望进球数之差。约定以**主队为被减数（$\lambda$）**，**客队为减数（$\mu$）**作差：
  $$\text{xGD} = \lambda - \mu$$

- **判定区间与实战含义映射**：

#### (1) 当 $\text{xGD} \ge 0$ （主队期望更高或持平）
| 净胜球差区间 ($\text{xGD}$) | 战力对抗判定 | 预测指导意义 |
| :--- | :--- | :--- |
| **$0 \le \text{xGD} < 0.3$** | **双方实力在伯仲之间** | 比赛势均力防，胜负难料。首选平局或双选对冲，比分集中在 1-1 / 0-0 / 1-0。 |
| **$0.3 \le \text{xGD} \le 0.6$** | **主队略占优势** | 主队小幅占优但防爆冷。首选主胜（1-0 / 2-1），防平局（1-1）。 |
| **$0.6 < \text{xGD} \le 1.0$** | **主队优势明显** | 主队控制比赛节奏，胜率极高。首选主胜（2-0 / 2-1 / 3-1），让球玩法倾向主胜/让平。 |
| **$\text{xGD} > 1.0$** | **主队拥有碾压优势** | 实力悬殊呈单向碾压。首选主队大胜（3-0 / 4-0 / 3-1），让球玩法建议让胜/让平。 |

#### (2) 当 $\text{xGD} < 0$ （客队期望更高，对应净胜球绝对值）
| 净胜球差区间 ($\text{xGD}$) | 绝对值区间 | 战力对抗判定 | 预测指导意义 |
| :--- | :--- | :--- | :--- |
| **$-0.3 < \text{xGD} < 0$** | **$0 < \vert\text{xGD}\vert < 0.3$** | **双方实力在伯仲之间** | 比赛势均力敌，胜负难料。首选平局或双选对冲，比分集中在 1-1 / 0-0 / 0-1。 |
| **$-0.6 \le \text{xGD} \le -0.3$** | **$0.3 \le \vert\text{xGD}\vert \le 0.6$** | **客队略占优势** | 客队小幅占优。首选客胜（0-1 / 1-2），防平局（1-1）。 |
| **$-1.0 \le \text{xGD} < -0.6$** | **$0.6 < \vert\text{xGD}\vert \le 1.0$** | **客队优势明显** | 客队掌控局势，胜率较高。首选客胜（0-2 / 1-2 / 1-3），让球玩法倾向客胜/让平。 |
| **$\text{xGD} < -1.0$** | **$\vert\text{xGD}\vert > 1.0$** | **客队拥有碾压优势** | 客队实力单向碾压。首选客队大胜（0-3 / 0-4 / 1-3），让球玩法建议让负/让平。 |

### 3. 模型胜平负概率 vs 市场胜平负预期概率

- **基本归一化要求**：
  无论是模型预测还是市场预期，胜平负三项概率（主胜 $P_h$、平局 $P_d$、客胜 $P_a$）之和必须**严格归一化等于 100%**：
  $$P_{home} + P_{draw} + P_{away} = 100\%$$

- **概率来源定义**：
  1. **模型胜平负概率 ($P_{model}$)**：
     通过参照 [`reference.md`](reference.md) 中的标准精算预测流程（包含十因子定量加权、双泊松期望进球及蒙特卡洛随机扰动模拟）推算得出的理论真实概率。
  2. **市场胜平负预期概率 ($P_{market}$)**：
     通过机构/竞彩官方实时胜平负赔率（$O_h, O_d, O_a$）扣除抽水 margin 后反推归一化的隐含概率：
     $$\text{Margin} = \frac{1}{O_h} + \frac{1}{O_d} + \frac{1}{O_a} - 1$$
     $$P_{market, h} = \frac{1 / O_h}{1 + \text{Margin}}, \quad P_{market, d} = \frac{1 / O_d}{1 + \text{Margin}}, \quad P_{market, a} = \frac{1 / O_a}{1 + \text{Margin}}$$

- **核心关键判别逻辑**：

| 现象与背离特征 | 逻辑根因与对冲分析 | 预测与投注决策指导 |
| :--- | :--- | :--- |
| **1. 模型与市场走向不一致**<br>*(例：模型看好主队 $P_{model, h} > P_{model, a}$，但市场看好客队 $P_{market, a} > P_{market, h}$)* | **模型可能存在误判或漏判**。<br>市场资金与赔率变动通常包含了最新的临场关键伤停、内部军心、战意微调或天气变故。 | 必须触发警报！复查十因子输入，**不可盲目单选**，建议首选双选对冲或放弃该场投注。 |
| **2. 模型低估主队**<br>*(例：$P_{market, h} > P_{market, m} + 5\%$，市场给出的主胜概率显著高于模型预测)* | **市场预期比模型更看好主队**。<br>机构与大资金掌握了模型未完全量化的隐藏利好（如主场魔鬼氛围、战术严重克制等）。 | **顺应市场热度与资金流，跟市场走**。倾向选择主队不败（主胜/平局）。 |

### 4. 球队稳定度指标（NB + 六维度信号判断模型）

- **定义与作用**：
  球队稳定度用于评估一支球队在近期比赛中表现的**可预测性**与**防爆冷下限**。模型基于朴素贝叶斯（Naive Bayes, NB）加权与六维度信号融合，判断球队是否处于稳定强队、神经刀队或崩盘状态。

- **足球球队稳定性六维模型**：

| 维度序号 | 维度名称 | 关键衡量指标 | 衡量与判断目标 | 定量评估与信号特征 |
| :--- | :--- | :--- | :--- | :--- |
| **①** | **战绩稳定维度** | 胜平负波动、近10场积分走势 | 评估球队战绩是否经常大起大落 | 连续无连败/稳步拿分为高稳定；胜负交替、起伏剧烈为低稳定。 |
| **②** | **进攻稳定维度** | 进球均值、期望进球 (xG)、射门质量 | 评估进攻端输出是否持续 | 每场能稳定创造 1.5+ xG 且连续多场有进球；极少出现进攻哑火。 |
| **③** | **防守稳定维度** | 失球均值、零封率、防守失误率 | 评估球队防守下限是否可靠 | 零封率高、被射门转化率低为高可靠防线；频繁低级失误则下限极低。 |
| **④** | **阵容稳定维度** | 首发 11 人变动率、核心伤停、轮换幅度 | 评估战术体系与战力是否容易波动 | 首发框架稳定、伤停少为高稳定；核心中轴线伤停/大轮换会导致战力陡降。 |
| **⑤** | **数据离散维度** | 进失球变异系数 ($CV = \frac{\sigma}{\mu}$)、表现方差 | 评估单场表现数据偏离均值的波动大小 | 进失球 $CV \le 0.35$ 为极小方差稳定型；$CV > 0.65$ 为大起大落神经刀型。 |
| **⑥** | **模型概率维度** | 多因素朴素贝叶斯 (NB) 概率一致性 | 评估各维度优势/劣势信号是否高度统一 | 六维信号方向协同一致（NB后验概率极化）则极易预测；信号冲突则降级下注仓位。 |

- **朴素贝叶斯 (Naive Bayes) 综合稳定度评分 ($S_{stability}$)**：
  根据六维独立信号概率乘积评估综合稳定度等级：
  $$S_{stability} = \prod_{i=1}^{6} P(\text{Stable} \mid \text{Dimension}_i)$$

- **稳定度关键判别规则**：

| 复合条件特征 | 球队类型形态 | 逻辑根因与下限分析 | 投注与预测决策指导 |
| :--- | :--- | :--- | :--- |
| **NB < 50% + CV < 1.0 + 零封率低** | **靠谱稳定型球队** | 数据方差小 ($CV < 1.0$)，虽极少大胜零封对手，但攻防输出极为平稳，模型后验不确定性极低。 | **下限可靠，按模型概率走**。<br>适合作为基胆单选或按半凯利公式稳健投注。 |
| **NB > 60% + CV > 1.2 + 零封率高** | **神经刀/上限高下限低型球队** | 虽然经常零封零暴击，但数据离散离差极大 ($CV > 1.2$)，胜负与攻防经常大起大落。 | **小心翻车爆冷！**<br>严禁单选重仓，必须防范下限崩盘，首选双选对冲或避开单场重仓。 |

### 5. 期望总进球数 (ETG) 与 95% 置信区间 (CI) 指标

- **期望总进球数 (Expected Total Goals, ETG)**：
  - **定义**：两队主客场期望进球数之和，即 $\text{ETG} = \lambda + \mu$。

- **ETG 进球格局区间判断**：

| ETG 数值区间 | 比赛格局判定 | 战术特征与预测指导 |
| :--- | :--- | :--- |
| **$\text{ETG} < 1.5$** | **小球局 / 沉闷格局** | 双方以防守为主、阵型收缩，进球数极少。推荐总进球 0 / 1 / 2 球玩法，比分集中在 0-0 / 1-0 / 0-1。 |
| **$1.5 \le \text{ETG} \le 2.5$** | **正常局 / 均衡格局** | 攻防拉锯、节奏适中，属于最常见的标准足球比分范畴。推荐总进球 2 / 3 球玩法，比分集中在 1-1 / 2-0 / 2-1 / 0-2。 |
| **$\text{ETG} > 2.5$** | **大球局 / 开放格局** | 双方打法大开大合或防线有明显纰漏，对攻猛烈。推荐总进球 3 / 4 / 5+ 球玩法，比分倾向 2-2 / 3-1 / 3-2。 |

- **95% 置信区间 (95% Confidence Interval, CI)**：
  - **定义与统计含义**：
    基于蒙特卡洛 10,000 次模拟采样分布，计算得到的包含 **95% 累积概率** 的总进球数离散区间 $[G_{min}, G_{max}]$。
    **含义**：在 95% 的统计概率下，单场比赛的最终总进球数必定落在这个范围内。
  - **示例**：
    若计算得到 **CI 区间为 [1, 3] 球**，意味着全场总进球大概率只能是 **1 球、2 球或 3 球**，不太可能是 0 球或 4+ 球。

- **极端比分 (Extreme Score) 爆冷防护机制**：
  - **定义**：总进球数落在 **95% CI 置信区间之外** 的极低概率比分（如 CI 以外的 0-0、4-1、5-0 等大比分屠杀或极限沉闷比分）。
  - **实战防爆冷作用**：
    虽然在统计学上属于小概率事件（发生率 $< 5\%$），但极端比分具有**超高赔率**与**大冷门对冲机制**。精算模型保留极端比分作为第三手推荐（防大冷门 / 大比分屠杀），用于利用轻仓博取超高回报率（High ROI）防范混沌黑天鹅爆冷。

### 6. 精确比分分布指标 (Top5 Correct Score Distribution)

- **定义与作用**：
  基于蒙特卡洛 10,000 次独立模拟频数统计出概率最高的前 5 位精确比分（Top 1 ~ Top 5）。比分分布形状揭示了比赛的进球集中度、变数大小及防守/对攻格局。

- **Top 5 比分分布判定规则**：

| 比分分布特征 | 离散与概率形态 | 比赛格局分析 | 预测与投注决策指导 |
| :--- | :--- | :--- | :--- |
| **Top 1 概率 $> 15\%$** | **高概率单点聚焦** | 比赛走向与比分高度明确，模项后验高度集中。 | **首选比分确定性高**。<br>可作为第一手比分推荐或比分单选基胆。 |
| **Top 1 ~ 5 概率离散** | **分布平缓/多点分散** | 比分概率无明显单峰，变数大，任何比分均有可能发生。 | **变数大，需谨慎考虑！**<br>严禁单重仓单一比分，建议采取多比分对冲或双过关。 |
| **0-0 排名 Top 1** | **极度沉闷防守格局** | 双方攻势受限、阵型极度收缩，防守大战。 | **防守闷战**。<br>主推 0-0 / 1-0 / 0-1 小球比分，防范半全场平平。 |
| **2-1 / 3-1 排名靠前** | **强攻对攻开放格局** | 双方打法大开大合，进攻端输出持续且防线有漏洞。 | **对攻大战**。<br>主推 2-1 / 3-1 / 2-2 大球比分，总进球数看好 3/4 球。 |

- **大小球与总进球数关键判别法则**：

| 判定维度 | 关键判别标准 | 决策指导与结论表达 |
| :--- | :--- | :--- |
| **1. 看峰值判断大球还是小球** | **观察 Top 1 ~ Top 3 概率峰值所落的比分类型**：<br>- 峰值落在 0-0、1-0、0-1、1-1 $\rightarrow$ **明确判定为小球局**；<br>- 峰值落在 2-1、3-1、2-2、3-2 $\rightarrow$ **明确判定为大球局**。 | 比分分布峰值决定了单场大球/小球的主基调，直接指导总进球数与 HAD/HHAD 串关的玩法方向。 |
| **2. 看 CI 区间判断总进球范围** | **结合 95% 置信区间 $[G_{min}, G_{max}]$ 锁死总进球数范围**：<br>- 比如 CI 为 $[1, 3]$ 球 $\rightarrow$ 总进球数必定大概率落在 1、2、3 球范畴内，排除 0 球与 4+ 球。 | CI 置信区间提供了总进球数下限与上限的安全边界，用于精准过滤不可能出现的离散进球选项。 |

### 7. 翻车概率 + 市场热度预警指标 (Upset Risk & Market Heat Alert)

- **翻车概率 (Upset Probability)**：
  - **定义**：热门球队（通常为强队/主胜热门）拿不下比赛的总概率。
    即 **翻车概率 = 弱队胜概率 + 平局概率**（对热门主队而言，$\text{P}_{upset} = P_{draw} + P_{away}$）。
  - **判定区间与含义映射**：

| 翻车概率区间 ($\text{P}_{upset}$) | 状态判定 | 策略指导与下注建议 |
| :--- | :--- | :--- |
| **$\text{P}_{upset} < 45\%$** | **热门稳** | 热门球队胜率高（$>55\%$），打出概率极大，盘口下限稳定。适合作为基胆单选。 |
| **$45\% \le \text{P}_{upset} \le 60\%$** | **有悬念** | 热门优势有限，弱队拿分风险不可忽视。建议防平局或双选不败。 |
| **$\text{P}_{upset} > 60\%$** | **乱战难控 / 博冷机会** | 热门极易翻车，局势混沌难控。**博冷大良机！** 重点关注让球客胜或高赔平局/客胜。 |

- **市场热度 (Market Heat)**：
  - **定义**：通过机构/竞彩官方赔率反推大众与大资金对热门球队看好的集中程度（隐含概率）。
  - **热度预警区间**：

| 市场热度区间 ($\text{Heat}_{market}$) | 市场状态 | 预警分析与陷阱防范 |
| :--- | :--- | :--- |
| **$\text{Heat}_{market} > 65\%$** | **热度偏高** | 大众资金过度追捧热门，买盘严重倾斜，赔率抽水打折严重。 |
| **$\text{Heat}_{market} > 72\%$** | **大热必死预警** | **历史上高冷爆冷高发区！** 机构资金过热吸筹，机构诱盘或让球盘口过深，爆冷风险极高。 |

- **翻车概率 + 市场热度 联合交叉决策逻辑**：

| 翻车概率 $\text{P}_{upset}$ | 市场热度 $\text{Heat}$ | 综合风险形态 | 核心决策与博冷/防爆策略 |
| :--- | :--- | :--- | :--- |
| **高翻车 ($\text{P}_{upset} > 60\%$)** | **高热度 ($\text{Heat} > 65\%$)** | **爆冷概率极大！** | **重点警惕，大热必死！**<br>严禁单选热门，必须重防平局或弱队独胜，博冷高收益玩法首选。 |
| **低翻车 ($\text{P}_{upset} < 45\%$)** | **低热度 ($\text{Heat} \le 65\%$)** | **热门大概率拿下** | **稳健无忧！**<br>热门球队不受筹码过分追捧且模型胜率扎实，可作为稳健串关胆码。 |
