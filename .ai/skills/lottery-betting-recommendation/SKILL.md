# 竞彩足球投注方案推荐 Skill

本 Skill 旨在指导 Agent 以**资深精算师（Actuary）**的专业角色，结合竞彩足球的实时赔率与十因子比赛预测模型，通过精算学、概率论、风险控制模型（如期望值 EV、凯利公式 Kelly Criterion）进行严谨的定量投资分析，为用户输出并保存最科学、最符合不同风险偏好（追求稳健与追求高 ROI）的投注方案。

## 准备阶段：运行预测与拉取竞彩赔率

在接收到用户的日期或特定场次请求后，必须严格执行以下双重数据准备流程，确保投注推荐**完全、严格基于 `/match-prediction` 的预测结论**：

1. **运行比赛预测**：
   对于需要分析的每一场比赛，必须**首先运行 `match-prediction` Skill** 进行十因子定量加权分析，生成完整的预测报告并保存在 `output/` 目录下（例如 `output/20260615_西班牙_vs_佛得角.md`）。

2. **拉取实时竞彩赔率**：
   运行 Python 脚本获取指定日期的竞彩比赛列表及 HAD（胜平负）、HHAD（让球胜平负）、TTG（总进球数）、HAFU（半全场）、CRS（比分）等玩法的实时赔率：
   ```bash
   python3 scripts/fetch_lottery_data.py --date "<YYYY-MM-DD>"
   ```

3. **运行投注方案生成脚本**：
   运行专门的严格投注推荐脚本，该脚本会自动扫描 `output/` 目录下的所有比赛预测报告，提取胜平负、比分和总进球数的预测结论，与实时竞彩赔率进行对比，计算期望值（EV）并生成最终的投注方案报告：
   ```bash
   python3 scripts/generate_betting_recommendation_strict.py --date "<YYYY-MM-DD>"
   ```

## 核心分析框架：提成率、归一化概率与期望值（EV）

Agent 必须执行以下完整的精算数据处理链：首先从体彩实时赔率中计算庄家抽水提成率，接着通过比例归一化还原 market 隐含概率，最后利用加权比例（0.8 模型 + 0.2 市场）混合出最终决策概率，以此进行期望值（EV）定量计算与资金分配。

### 1. 庄家抽水提成率与返还率计算
对于某玩法下所有互斥的投注选项，其赔率分别为 $O_1, O_2, \dots, O_n$。
- **原始隐含概率**：$IP_i = \frac{1}{O_i}$
- **超额赔率总和（Overround）**：$S = \sum_{i=1}^n \frac{1}{O_i}$
- **庄家抽水提成率（Margin / Vig）**：$M = S - 1$
- **官方理论返还率（Payout Ratio）**：$R = \frac{1}{S}$

### 2. 归一化市场隐含中奖概率（去抽水概率）
利用比例分配法（Proportional Method）消除庄家抽水的影响，还原市场的无偏见共识概率：
$$P_{implied}(i) = \frac{IP_i}{S} = \frac{\frac{1}{O_i}}{\sum_{j=1}^n \frac{1}{O_j}}$$

### 3. 双源加权比例概率融合
为了将模型的深度预测优势（Alpha）与市场的资本流共识（Beta）有机结合，最终决策概率 $P_{final}$ 必须采用**定制加权比例（0.8 : 0.2）**进行线性混合：
$$P_{final}(i) = 0.8 \times P_{predicted}(i) + 0.2 \times P_{implied}(i)$$
- $P_{predicted}$：由十因子预测模型推导出的该选项发生概率（来自 `match-prediction`）。
- $P_{implied}$：通过实时赔率计算并去抽水后的归一化中奖概率。

### 4. 球队平均年龄与巅峰加成因子 (Squad Average Age Factor)
本模型将各参赛队的平均年龄（Squad Average Age）作为衡量战术成熟度、体能充沛度及巅峰战斗力的核心指标。
- **最佳巅峰年龄**：足球运动员的巅峰期黄金段一般在 24.5 ~ 27.5 岁之间，本模型以 **26.0 岁** 为最完美巅峰中心。
- **巅峰年龄效率函数**：使用高斯分布（高斯效率钟形曲线）建模每支球队的巅峰战力效率：
  $$E(A) = e^{-\frac{(A - 26.0)^2}{2 \times 1.8^2}}$$
  其中 $A$ 为球队的平均年龄，$1.8$ 岁为分布的标准差。平均年龄越接近 26.0 岁，该项效率值越趋近于 100%。
- **胜率加成调整**：根据两队巅峰年龄效率之差计算净胜率加成：
  $$\text{Age\_Adj} = (E(A_1) - E(A_2)) \times 3\%$$
  该加成直接调整基础胜负预测概率（上限为 $\pm 3.0\%$），完美巅峰期的明星/新秀球队在面对老龄化或过于稚嫩的对手时，将获得显著的赔率精算增益。

### 5. 期望值（EV）计算公式
对于任意投注选项，其最终决策期望值计算公式为：
$$EV = P_{final} \times O - 1$$
- **判定标准**：
  - **$EV > 0$**：代表该投注具有**正期望值（性价比高）**，属于长期投资有利可图的“价值投注”（Value Bet）。
  - **$EV \le 0$**：代表该投注性价比低，不建议作为首选。

### 6. 凯利公式仓位控制（Kelly Criterion）
对于 $EV > 0$ 的价值投注，使用凯利公式计算推荐的投注资金比例（仓位 $f^*$）：
$$f^* = \frac{EV}{O - 1}$$
为了控制风险，实际推荐时采用**半凯利（Fractional Kelly, 比例为 50%）**进行风险稀释：
$$\text{推荐仓位} = 0.5 \times f^*$$

### 7. 固定本金（200元）分配与最低投注限制
- **固定本金**：为了提供最符合大众日常娱乐的实操账单，每次计算和输出黄金投注方案时，必须**统一按照 200 元（RMB）的固定本金**进行各档位资金的精密拆分。
- **最低投注约束**：根据中国体育彩票的相关规定，**单次最低投注金额必须为 2 元**（即 1 注票价，且必须为 2 元的整数倍，如 2, 4, 6, 8, ... 元）。
  - 在计算分配资金时，如果某高风险/极轻仓选项根据比例得出的计算金额小于 2 元（或非整数），必须**强制向上取整或向下调整为 2 元**。
  - 所有分配金额必须是 **2 元的整数倍**，最终各选项分配金额之和必须**刚好等于 200 元**（若因四舍五入无法对齐，可通过微调高概率胆码的资金来补齐）。

### 8. 混合过关（Mixed Parlay）精算模型与官方规则限制
在竞彩足球中，混合过关允许跨玩法（HAD-胜平负、HHAD-让球胜平负、TTG-总进球数、CRS-比分）组合多场不同的比赛，利用期望值（EV）的乘数效应将多个正 EV 价值点融合成更具弹性的高性价比投资组合。
- **组合概率与赔率公式**：
  - **组合总赔率**：$O_{combo} = \prod_{i=1}^N O_i$
  - **组合总概率**：$P_{combo} = \prod_{i=1}^N P_{final}(i)$
  - **组合期望值**：$EV_{combo} = \prod_{i=1}^N (EV_i + 1) - 1$
- **官方玩法串关场数合规限制**：
  - 混合过关中若**包含比分（CRS）**，最大串关场数限制为 **$\le 4$ 场**。
  - 混合过关中若**包含总进球数（TTG）且不含比分**，最大串关场数限制为 **$\le 6$ 场**。
  - 混合过关中若**仅含胜平负（HAD）或让球胜平负（HHAD）**，最大串关场数限制为 **$\le 8$ 场**。
  - 为了控制概率回撤并保证中奖概率，黄金投注推荐中推荐的组合应以 **2串1（2场串关）或 3串1（3场串关）** 为主。
- **混合过关半凯利仓位公式**：
  $$f^*_{combo} = \frac{EV_{combo}}{O_{combo} - 1}$$
  $$\text{推荐仓位} = 0.5 \times f^*_{combo} = 0.5 \times \frac{EV_{combo}}{O_{combo} - 1}$$
  单项推荐仓位上限强制设定为 **10.0%**，以规避极端波动风险。

## 投注方案组合策略

作为一名专业的精算师，Agent 必须根据不同的风险偏好与投资目标，对计算出的正 EV 选项进行精算分级和组合。**所有入选黄金投注方案推荐（包括稳健单场、性价比串关、高回报博冷）的投注项目，其最终决策期望值（EV）必须严格大于 8%（即 $EV > 8\%$）**。不满足该期望值阈值的选项均不被允许列入黄金推荐方案。

### 1. 追求稳健策略（Low Risk, Stable Growth）
该策略旨在最大化胜率，严格控制回撤，适合追求稳健、规避高风险的投资者。
- **稳健单场推荐（胜平负/让球胜平负单场）**：
  - 筛选出 **$EV > 8\%$** 且预测概率 $P \ge 55\%$ 的选项。优先选择主不败或客不败等高胜率受让盘口。
  - 推荐仓位控制在 3% - 5% 之间。
- **稳健 2串1 组合**：
  - 选择 2 场预测概率极高（$P \ge 60\%$）且单场 **$EV > 8\%$** 的稳胆选项进行串关，且组合总期望值也必须满足 **$EV > 8\%$**。
  - 组合总胜率控制在 $35\%$ 以上，总赔率介于 $2.0 \sim 3.5$ 之间，确保中奖确定性。

### 2. 追求投资回报率策略（High ROI, Capital Appreciation）
该策略旨在正 EV 的前提下最大化长期资金增长率，博取超额收益，适合追求高投资回报率、有一定风险承受能力的投资者。
- **高 ROI 性价比串关（2串1 / 3串1）**：
  - 选择 2-3 场 $EV \ge 8\%$ 且彼此独立的比赛，将高性价比的选项组合成混合过关。
  - 组合总赔率介于 $3.5 \sim 8.0$ 之间，利用期望值乘数效应实现资金的快速增值。
- **高回报特色玩法博冷（比分/半全场/总进球数）**：
  - 结合预测的精确比分和总进球数，在比分（CRS）或半全场（HAFU）中寻找赔率极高（$O \ge 8.0$）且 **$EV > 8\%$** 的冷门高价值选项。
  - 推荐仓位控制在 1% - 2% 之间（娱乐轻仓），以极小的风险博取极高的回报。

## 输出与文件保存规范

### 1. 文件保存与命名规范
- **保存路径**：本项目根目录下的 `output/` 文件夹（若不存在则自动创建）。
- **文件名规则**：`日期（年月日）_投注方案.md`。
  - **日期格式**：采用 `YYYYMMDD` 八位数字格式。日期以比赛实际进行的北京时间/竞彩开售日期为准（例如：`20260620_投注方案.md`）。
- **保存内容**：必须包含完整的投注方案报告，包含概述表格、EV定量分析表、推荐组合及投资建议。

### 2. 运行日志与数据回溯规范
为了方便回溯概率值、回溯进球数、胜平负数值及比分等核心精算指标，每次运行推荐脚本时，系统会自动在根目录下创建 `logs/` 文件夹，并采用以下结构进行多格式持久化记录：
- **保存路径**：根目录下 `logs/<YYYYMMDD>/`（按照业务比赛日期创建子目录，例如 `logs/20260621/`）。
- **日志文件分类**（按照脚本名称命名）：
  - **文本运行日志 (`<script_name>.log`)**：采用双重流记录（`DualLogger`），完整捕获终端输出的所有文本日志（包括读取文件、API拉取状态、解析详情、推荐结果等），用于行为回溯。
  - **结构化 JSON 轨迹 (`<script_name>.json`)**：将完整的 `analyzed_matches` 原始数组以 JSON 格式保存。其中包含每场比赛的进球数期望、基于蒙特卡洛/双泊松的最终精确比分模拟概率分布 $P_{sim}(X, Y)$、比分最优解 $\arg\max_{(X, Y)} P_{sim}(X, Y)$ 及其概率、双源融合前的模型预测概率和市场隐含概率，以及最终融合概率、期望值（EV）和半凯利仓位配比。这为高精度的回溯、量化复盘和统计提供了完备的机器可读数据源。
