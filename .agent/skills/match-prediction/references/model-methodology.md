# 模型方法

## 1. 数据窗口

只使用开球时间之前状态为 `FINISHED` 的比赛。当前实现默认读取最近两个赛季，并按时间顺序更新俱乐部 ELO。赛季早期或升班马样本不足时，结果标记为 `insufficient`。

## 2. 主场 ELO

主队期望结果为：

$$E_h = \frac{1}{1 + 10^{-((R_h + H)-R_a)/400}}$$

其中 $R_h$、$R_a$ 是赛前评级，$H$ 是可配置主场优势。赛后更新为：

$$R'_h = R_h + K(S_h-E_h), \quad R'_a = R_a-K(S_h-E_h)$$

默认参数只是待回测基线，`calibration_status` 必须保留 `baseline_pending_walk_forward`，不得描述成已校准参数。

## 3. 动态进球参数

联赛主客场平均进球从输入历史现场计算。球队近期进球和失球使用指数衰减，并向联赛均值收缩：

$$\bar g_{shrunk} = \frac{w\bar g + n_0\bar g_{league}}{w+n_0}$$

主客队期望进球由联赛主客场基准、近期攻防比率和温和的中立 ELO 强度因子共同生成。输出会限制在合理的正数区间，限制值属于实现保护，不是经验结论。

## 4. 比分分布

第一版使用独立双泊松：

$$P(X=x,Y=y)=\frac{e^{-\lambda}\lambda^x}{x!}\frac{e^{-\mu}\mu^y}{y!}$$

比分网格归一化后派生 HAD、HHAD、TTG 和 CRS 概率。Dixon-Coles 只能在走步回测证明改善低比分拟合后替换当前核心。

## 5. 随机模拟

模拟器使用对数正态扰动传播 xG 不确定性，并对均值作 $-\sigma^2/2$ 修正。没有观测输入时，红牌、点球、裁判和天气调整全部为零。相同 seed 必须产生相同结果。

## 6. 赛前上下文

伤停、预计首发、教练更替、休息天数和欧战旅行可以进入用户解释，但当前实现没有经过校准的数值 connector。不得凭主观分数修改模型概率；需要数值化时，先扩展数据契约并完成走步回测。
