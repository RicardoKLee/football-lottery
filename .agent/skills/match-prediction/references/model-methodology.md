# 模型方法

## 1. 数据窗口与比分审计

只使用开球时间之前状态为 `FINISHED` 的比赛。比分必须经过审计，严格限定为常规时间 90 分钟（含伤停补时）非负整数比分，剔除点球大战和加时赛。
按时间顺序更新球队 ELO。样本不足或图不连通时，结果标记为 `insufficient`。

## 2. 通用 ELO 与场地处理

当比赛在主队主场（`venue == "home"`）进行时，主队赛前期望为：

$$E_h = \frac{1}{1 + 10^{-((R_h + H)-R_a)/400}}$$

其中 $R_h$、$R_a$ 是赛前评级，$H$ 是主场优势参数。
当比赛在中立场（`venue == "neutral"`）进行时，双向消除主场优势（$H=0$）：

$$E_h = \frac{1}{1 + 10^{-(R_h-R_a)/400}}$$

若场地未知（`venue == "unknown"`），模型以 `venue_unknown` 拒绝，不设默认主场优势。
赛后更新公式为：

$$R'_h = R_h + K(S_h-E_h), \quad R'_a = R_a-K(S_h-E_h)$$

默认参数为待回测基线，`calibration_status` 必须保留 `baseline_pending_walk_forward`。

## 3. 动态进球参数与样本池隔离

赛事主客场平均进球从输入历史现场计算。球队近期进球和失球使用指数衰减，并向基准均值收缩：

$$\bar g_{shrunk} = \frac{w\bar g + n_0\bar g_{league}}{w+n_0}$$

- **中立场修正**：中立场比赛进球期望取消主场基准修正，主客双方使用对称期望进球计算。
- **样本池隔离**：俱乐部赛事样本池与国家队样本池严格物理隔离；跨赛事历史必须显式声明样本池并进行图连通性校验；连通性校验只基于开球时间之前的样本，杜绝未来信息泄漏。

## 4. 比分分布

使用通用双泊松模型（`football-elo-poisson`）：

$$P(X=x,Y=y)=\frac{e^{-\lambda}\lambda^x}{x!}\frac{e^{-\mu}\mu^y}{y!}$$

比分网格归一化后派生 HAD、HHAD、TTG 和 CRS 概率。

## 5. 随机模拟

模拟器使用对数正态扰动传播 xG 不确定性，并对均值作 $-\sigma^2/2$ 修正。没有观测输入时，红牌、点球、裁判和天气调整全部为零。相同 seed 必须产生相同结果。

## 6. 赛前上下文

伤停、预计首发、教练更替、休息天数等赛前信息可作为面向用户的定性说明，但当前实现不包含数值化修正 connector。不得凭主观分数修改模型概率。
