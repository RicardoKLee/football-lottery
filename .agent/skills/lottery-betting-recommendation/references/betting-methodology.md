# 投注计算方法

## 玩法状态与去抽水市场概率

每项玩法在评估前必须核查 `market_status[market] == "open"`。十进制赔率为 $O_i$：

$$q_i=1/O_i,\quad Q=\sum_i q_i,\quad P_{market,i}=q_i/Q$$

庄家边际为 $Q-1$，理论返还率为 $1/Q$。该归一化只适用于同一玩法下互斥且完整的在售选项。

## EV 与风险缓冲

$$EV=pO-1$$

当前策略另设显式概率折减 $h$（默认 3%）：

$$p_c=\max(0,p-h),\quad EV_{low}=p_cO-1$$

$p_c$ 不是由统计抽样得到的置信下界，而是保守风控缓冲。

## 凯利与资金管理

$$f^*=\frac{p_cO-1}{O-1}$$

当前实现使用半凯利（$f = 0.5 \times f^*$），单项上限 5%，总敞口上限 20%。
金额基于 bankroll 计算并按投注单位向下取整；系统严禁按候选项相对权重重新归一化，也不得强制花完 bankroll。未下注金额保留为现金。

## 串关

只有不同比赛才能组成 2 串 1。当前计算暂按跨场独立：

$$p_{combo}=\prod_i p_i,\quad O_{combo}=\prod_i O_i$$

实际比赛仍可能受到共同信息影响，因此串关默认关闭，显式启用时使用更低的四分之一凯利和 2% 单项上限。
