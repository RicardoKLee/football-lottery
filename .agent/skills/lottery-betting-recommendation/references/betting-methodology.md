# 投注计算方法

## 玩法状态与去抽水市场概率

每项玩法在评估前必须核查 `market_status[market] == "open"`。十进制赔率为 $O_i$：

$$q_i=1/O_i,\quad Q=\sum_i q_i,\quad P_{market,i}=q_i/Q$$

庄家边际为 $Q-1$，理论返还率为 $1/Q$。该归一化只适用于同一玩法下互斥且完整的在售选项。

## EV 与风险缓冲

$$EV=pO-1$$

当前策略设显式概率折减 $h$（默认 3%）：

$$p_c=\max(0,p-h),\quad EV_{low}=p_cO-1$$

$p_c$ 不是由统计抽样得到的置信下界，而是保守风控缓冲。

## 单关销售限制与候选分流

在体彩官方竞彩中，并非所有玩法均开放单关固定奖购买：

1. **单关开售状态（`single_status`）**：
   - 官方快照中维护每场比赛各玩法的单关开售状态。一般比分（CRS）普遍开售单关，而胜平负（HAD）、让球（HHAD）和总进球（TTG）通常仅在部分焦点赛事开放单关。
   - 选项进入单关投注建议的前提是 `single_status[market] == True`。若未开放单买，则必须从单关推荐中坚决剔除，避免提供彩民无法在终端机购买的注单。

2. **候选分流机制**：
   - **单关池**：严格限定为 `eligible == True` 且 `single_allowed == True` 的选项，分项涵盖 **胜平负/让球胜平负**、**总进球数 (TTG)** 与 **比分 (CRS)**，每场比赛保留各玩法维度的最佳选项，杜绝玩法间互相压制；
   - **串关池**：包含各场比赛各玩法维度（胜平负/让球、进球数、比分）的全部优质达标选项，未开通单关的优质选项在此处得到充分利用；
   - **标注与审计**：所有被单关过滤的优质选项记录拒绝代码 `single_betting_not_allowed`，并在报告中清晰列明，保证策略透明度。

## 凯利与资金管理

$$f^*=\frac{p_cO-1}{O-1}$$

单关实现使用半凯利（$f = 0.5 \times f^*$），单项上限 5%，总敞口上限 50%。
金额基于 bankroll 计算，默认按投注单位（2 元）进行半单位阈值取整（当理论金额达到 0.5 个单位即 1 元以上时，配置 1 注面额 2 元，防止高赔率正期望玩法如进球数与比分在小额本金下被截断归零），且严格受最大总敞口上限约束。未下注金额保留为现金。

## 串关与混合过关

系统同时提供单关投注建议与 **2 串 1**、**4 串 1** 投注建议（支持并优先推荐跨玩法混合过关）：

1. **跨场混合与排他规则**：
   - 允许跨场混合不同玩法（胜平负 HAD、让球胜平负 HHAD、总进球 TTG、比分 CRS）。
   - 同一场比赛只能选入 1 项玩法进入串关，严格禁止同场玩法组合（$\text{len}(\text{unique}(match\_ids)) == N$）。
   - 优先推荐跨玩法组合（如 `HHAD+TTG`、`CRS+HHAD`、`HAD+TTG+CRS` 等真正意义上的混合过关），并在组合标签中显式标注混合维度。
   - 官方关数上限约束：混合比分（CRS）或半全场（HAFU）时组合最多 4 关；总进球最多 6 关；胜平负/让球最高 8 关。系统支持的 2 串 1 与 4 串 1 均严格符合此上限。

2. **联合概率与赔率（独立性假设）**：
   $$p_{combo}=\prod_{i=1}^N p_i,\quad p_{c,combo}=\prod_{i=1}^N p_{c,i},\quad O_{combo}=\prod_{i=1}^N O_i$$
   $$EV_{combo}=p_{combo}O_{combo}-1,\quad EV_{low,combo}=p_{c,combo}O_{combo}-1$$

3. **仓位与风控**：
   - 串关使用更保守的四分之一凯利（$f = 0.25 \times f^*$），单项上限 2%。
   - 组合排序综合考虑跨玩法混合属性与夏普比率（$EV_{low} / \sigma$），防止极端高赔长尾注单占用过多推荐位。
   - 纳入全组合总敞口统一受 50% 上限控制，确保组合整体风险受控。
